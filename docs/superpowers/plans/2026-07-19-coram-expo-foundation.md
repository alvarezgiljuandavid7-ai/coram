# CorAM Expo Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a native Expo foundation under `mobile/` while preserving the existing Vite web application and introducing only the minimum shared TypeScript boundaries needed by both clients.

**Architecture:** Keep `src/` as the existing web product and add `mobile/` as an Expo SDK 57 application using Expo Router. Configure npm workspaces for `mobile` and private packages, then share pure domain contracts and design tokens without sharing platform UI or Supabase client construction.

**Tech Stack:** React 19, Vite 8, TypeScript 5.9, Vitest 4, npm workspaces, Expo SDK 57, React Native 0.86, Expo Router, EAS configuration.

---

## File Structure

### Root files modified

- `package.json`: register npm workspaces and native validation commands without changing existing web scripts.
- `package-lock.json`: record workspace and Expo dependency graph generated by npm.
- `.gitignore`: exclude Expo state, native exports, and temporary build output.
- `tsconfig.json`: include shared packages in the existing type check.
- `.env.example`: retain existing Vite variables and document native variable names without values.
- `README.md`: document separate web and mobile commands.

### Web compatibility files modified

- `src/types.ts`: consume and re-export the shared `ContentStatus` contract.
- `src/theme/coramTokens.ts`: re-export shared CorAM tokens so existing imports remain stable.

### Web-side contract tests created

- `src/app/mobileWorkspace.test.ts`: verify workspace scripts and ignored native output.
- `src/app/mobileNavigationFoundation.test.ts`: verify the native route tree and ensure it is not a WebView wrapper.

### Shared packages created

- `packages/domain/package.json`: private pure TypeScript package manifest.
- `packages/domain/src/content.ts`: shared content status vocabulary.
- `packages/domain/src/roles.ts`: shared role vocabulary and type guard.
- `packages/domain/src/index.ts`: public package exports.
- `packages/domain/src/index.test.ts`: contract tests.
- `packages/design-tokens/package.json`: private token package manifest.
- `packages/design-tokens/src/index.ts`: shared semantic colors, spacing, radii, and existing action colors.
- `packages/design-tokens/src/index.test.ts`: token contract tests.

### Native application created

- `mobile/package.json`: Expo workspace manifest generated for SDK 57 and linked to shared packages.
- `mobile/tsconfig.json`: Expo TypeScript configuration.
- `mobile/App.tsx`: temporary blank-template entry removed when Expo Router is activated.
- `mobile/index.ts`: temporary blank-template bootstrap removed when Expo Router is activated.
- `mobile/expo-env.d.ts`: Expo type reference created when Expo Router is activated.
- `mobile/app.config.ts`: non-secret Expo application configuration.
- `mobile/eas.json`: development, preview, and production build profiles without credentials.
- `mobile/.env.example`: names of public native environment variables only.
- `mobile/assets/icon.png`: copied from the current CorAM icon.
- `mobile/assets/adaptive-icon.png`: copied from the current maskable icon.
- `mobile/assets/splash-icon.png`: copied from the current CorAM icon.
- `mobile/app/_layout.tsx`: root safe-area, status-bar, and native stack shell.
- `mobile/app/index.tsx`: deterministic entry redirect.
- `mobile/app/(auth)/_layout.tsx`: isolated future authentication stack.
- `mobile/app/(auth)/index.tsx`: explicit foundation-state authentication screen.
- `mobile/app/(app)/_layout.tsx`: isolated future authenticated stack.
- `mobile/app/(app)/index.tsx`: CorAM native foundation screen.
- `mobile/src/components/FoundationScreen.tsx`: reusable native foundation presentation.
- `mobile/src/components/FoundationScreen.styles.ts`: React Native styles consuming shared tokens.
- `mobile/src/theme/coramTheme.ts`: native semantic theme adapter.
- `mobile/README.md`: native setup and validation instructions.

export function FoundationScreen({

  return (
    <SafeAreaView style={styles.safeArea}>
      <View style={styles.screen}>

            source={require('../../assets/icon.png')}
